# SOP-03 Ammonia, pH, temperature, alkalinity

## Limits
| Parameter | Limit | Source |
|---|---|---|
| Un-ionised ammonia (NH3) | optimum **< 0.05 mg/L**; growth and feed intake depressed from **0.1 mg/L** | SDSU FS963-02 (2010) |
| pH | best growth **7–9** | SDSU FS963-02 (2010) |
| Temperature | optimum **22–29 °C** | SDSU FS963-02 (2010) |
| Alkalinity | **100–150 mg/L as CaCO3** | Khanjani et al. (2024) |
| TSS | usually **< 500 mg/L** (systems run < 1,000) | Khanjani et al. (2024) |

## Rules
- Always say whether a value is **TAN** or **un-ionised NH3**. They are different.
- NH3 ≥ 0.05 mg/L → PERHATIAN; NH3 ≥ 0.1 mg/L → BAHAYA. If DO > 3 mg/L, consider molasses per SOP-01; otherwise aerate first.
- pH outside 7–9 or temperature outside 22–29 °C → flag to the supervisor. The demo has no pH-correction tool.
- The demo receives NH3 from the (simulated) sensor feed; it does not calculate NH3 from TAN.
