# SOP-02 Dissolved oxygen (DO) and aeration

## Limits (SDSU FS963-02, 2010)
- Optimum growth for Nile tilapia: **DO > 3 mg/L**.
- Survival limit: 0.1 mg/L. This is NOT a target; it only explains why low DO is an emergency.

## Rule
- If DO ≤ 3 mg/L in any reading → status BAHAYA, propose `start_aerator` for the pond (demo default 120 min), supervisor approves.
- DO tends to fall at night when algae and bacteria respire and no photosynthesis happens; check the overnight minimum in every morning briefing.
- Do not add molasses while DO ≤ 3 mg/L: molasses > 0.12 g/L crashed DO from 3.2 to 1–1.5 mg/L (Pérez-Fuentes et al. 2016).

## Roadmap note (not in demo)
- A VFD-controlled aeration blower cut energy use by 25% in a UF/IFAS case (EDIS FA247). Real aerator control is ROADMAP; the demo only logs the approved call.
